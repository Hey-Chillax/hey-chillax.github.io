# Method diagrams (draw.io)

The six schematic figures on the project pages: `opd-takeover` and `scr-steplevel` (method frameworks),
`opd-pipeline` and `scr-pipeline`, and the home-page thumbnails `card-opd` and `card-scr`.
Each is generated by Python as a draw.io file, in English and Chinese with the same layout, exported with
draw.io Desktop, and rewritten into a page-ready SVG whose colours are CSS variables.

| File | Role |
| --- | --- |
| `dlib.py` | Palette (soft fills, darker same-hue strokes), text measurement, the `Fig` builder |
| `fig_<name>.py` | One figure: `WIDTH`, `LABEL` / `LABEL_ZH` (aria-labels), `build(variant, lang)` |
| `build.py` | Generate → export (draw.io CLI) → webify → PNG previews; `--final` writes `out/` |
| `webify.py` | Export → page SVG: drops fallbacks, sets viewBox / role / aria-label, colours → `var(--dg-*)`, web fonts |
| `render.js` | Preview renderer (Playwright): the SVG inline with the site's Comic Neue and the colour variables |
| `diagram-colors.css` | The `--dg-*` variables, light and dark (`python3 tools/drawio/webify.py --css` rewrites it) |
| `src/<name>/` | The `.drawio` of every round: `rNa` aesthetic, `rNi` innovative, `rNm` merged (opens in draw.io) |
| `out/<name>.en.svg` | The finals (English only): round 6, merged; the two pipelines are round 7 (below) |

Build one figure (Pillow is needed, so use a virtualenv; previews need node with Playwright):

```bash
DRAWIO_SCRATCH=/some/tmp DRAWIO_NODE_PATH=/path/to/node_modules \
  python3 tools/drawio/build.py opd_takeover r6m --lang en --final r6m --dark
```

Since 2026-11-17 the homepage shows English figures only: rounds 4-6 are built with `--lang en`, and the finals are
`out/<name>.en.svg` (round 6, merged). The `out/<name>.zh.svg` files are the round-3 Chinese finals, no longer used.
On 2026-11-21 the two pipelines were replaced by the interview deck's version (resume repo,
`ppt_src/figures/drawio/fig_*_pipeline.py`, final r3m), ported back as round 7 (`r7m`) at the page's width and type
scale; the deck drew the score staircase in the data charts' blue, here it uses the palette's dark sky.

On the page the SVG must be inlined (an `<img>` cannot see the page's CSS variables), with
`diagram-colors.css` loaded; text uses `'YZ Hand'` (Comic Neue), symbols Times New Roman.
Units: one draw.io unit is one pixel at the intended width: 720 px for the frameworks (from round 4; rounds 1-3 were
880 px, which the 724 px article column showed at 0.82 of their size) and the pipelines, 300 px for the cards; the
exported viewBox is one pixel larger because of draw.io's half-pixel crop. Previews render each variant at its own
width. Labels that other items are placed after (keys) are spaced with `dlib.web_w`, the page font's widths, because
`label_w` measures Comic Sans MS, which is wider than the Comic Neue the page shows.
