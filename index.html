I work on large language models, mainly multimodal LLMs and post-training, with a research focus on efficient long-video understanding. In my recent projects I built two complete post-training pipelines: SFT → OPD → RL, which teaches a small model long chain-of-thought math reasoning, and SFT → agentic RL for long-horizon, multi-turn tool-calling agents.

我的方向是大模型，主要做多模态大模型和后训练，研究重点是高效长视频理解。在最近的项目中，我搭建了两条完整的后训练流程：一条是让小模型学会长链数学推理的 SFT → OPD → RL，另一条是面向长程多轮工具调用 Agent 的 SFT → Agentic RL。

Scaffold-OPD

An SFT → OPD → RL post-training pipelineSFT → OPD → RL 后训练全流程

Teaches a 1.7B student long chain-of-thought math from a 4B teacher. The core stage uses Scaffold-OPD: the student generates on its own, the teacher steps in briefly, only where the student misses a reflection or the conclusion, and the whole trajectory is then distilled token by token.让 1.7B 学生向 4B 老师学习长链数学推理。核心阶段采用 Scaffold-OPD：学生自行 rollout，老师只在学生想不到的反思或收尾处短暂接管，再对整条轨迹做 token 级蒸馏。

AGENTIC RL2025.09 – 2025.12

StepCredit-RL

SFT → agentic RL for long-horizon, multi-turn tool-calling agents长程多轮工具调用 Agent 的 SFT → Agentic RL 全流程

Covers the whole pipeline: expert demonstrations, SFT, multi-turn RL and paired evaluation. RL uses StepCredit-RL: steps taken from the same environment state in different trajectories form a group, and each step's relative advantage, computed from what followed, is added to the episode-level advantage — no critic, no extra rollouts.覆盖专家示范 → SFT → 多轮 RL → 配对评测的完整流程。RL 采用 StepCredit-RL：把不同轨迹中相同环境状态下的步骤归为一组，按后续回报计算步级相对优势，与整局优势相加，无需 critic 与额外 rollout。
