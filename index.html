I work on large language models: multimodal LLMs, with a research focus on efficient long-video understanding, and post-training — SFT, reinforcement learning and on-policy distillation (OPD). My recent projects build two complete pipelines: SFT → OPD → RL for long chain-of-thought math reasoning in a small model, and SFT → agentic RL for long-horizon, multi-turn tool-calling agents.

我做大模型方向：多模态大模型，研究重点是高效长视频理解；以及后训练，包括 SFT、强化学习和在线蒸馏（OPD）。最近的两个项目各走通了一条完整流程：让小模型学会长链数学推理的 SFT → OPD → RL，以及长程多轮工具调用 Agent 的 SFT → Agentic RL。

Scaffold-OPD

Teaches a 1.7B student long chain-of-thought math from a 4B teacher. StepCredit-RL

SFT → agentic RL for multi-turn tool-calling agents多轮工具调用 Agent 的 SFT → Agentic RL 全流程

Expert demonstrations, SFT, multi-turn RL and paired evaluation. RL adopts a step-level relative advantage that compares actions taken from the same environment state, so the agent learns which steps mattered without a critic or extra rollouts.专家示范 → SFT → 多轮 RL → 配对评测。RL 采用按相同环境状态分组的步级相对优势，不需要 critic 和额外 rollout，就能区分哪一步是关键动作。
