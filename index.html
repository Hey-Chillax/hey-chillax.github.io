Scaffold-OPD2026.09 – 2026.11

An SFT → OPD → RL post-training pipelineSFT → OPD → RL 后训练全流程

Teaches a 1.7B student long chain-of-thought math from a 4B teacher. The core stage uses Scaffold-OPD: the student generates on its own, the teacher steps in briefly only where the student would miss a reflection or the conclusion, and the whole trajectory is then distilled token by token. The student–teacher relay runs inside vLLM speculative decoding.

让 1.7B 学生向 4B 老师学长链数学推理。核心阶段采用 Scaffold-OPD：学生自行生成，老师只在学生想不到的反思或收尾处短暂接管，再对整条轨迹做 token 级蒸馏；师生接力生成基于 vLLM 投机解码实现。

Four-benchmark math average 25.4 → 46.9 in 40 steps, +6.2 over standard OPD.4 项数学基准平均分 25.4 → 46.9（训练 40 步），比标准 OPD 高 6.2。

StepCredit-RL2025.09 – 2025.12

SFT → agentic RL for long-horizon, multi-turn tool-calling agents长程多轮工具调用 Agent 的 SFT → Agentic RL 全流程

The RL stage uses StepCredit-RL: steps that start from the same environment state in different trajectories form a group, each step's advantage is computed from the return that followed it, and this is added to the episode-level advantage — no critic and no extra rollouts.

RL 阶段采用 StepCredit-RL：把不同轨迹中处于相同环境状态的步骤归为一组，按之后的回报计算步级优势，再与整局优势相加；不需要 critic，也不需要额外 rollout。

ALFWorld success 98.6% / 94.0% (seen / unseen) after SFT and 100 RL steps; 82.9% vs 70.7% against GRPO, 200 steps from the base model (seen, p = 0.006).ALFWorld 成功率 98.6% / 94.0%（seen / unseen，SFT 后训练 100 步 RL）；从基座训练 200 步，对比 GRPO 为 82.9% vs 70.7%（seen，p = 0.006）。
